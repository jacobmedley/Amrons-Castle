# Contributing

Install with `npm ci`, then run `npm run dev`. Before submitting changes, run `npm run typecheck`, `npm test` and `npm run build`.

Preserve Amron and the other persistent identities. Models and tasks may change without renaming characters. Keep demo data visibly fictional. Never turn missing, stale or partially read records into confirmed activity, and never infer runtime-accepted model settings from requested settings.

Keep the scene independent from backend adapters. The standalone demo must remain usable without a backend or credentials. Integration credentials belong on the host, never in this repository or a browser bundle. Avoid automatically running providers or approving work from observation code.

For visual changes, inspect desktop and phone layouts, keyboard access, zoomed selection and reduced motion. Use original or appropriately licensed assets and retain their provenance. Do not add source game screenshots or extracted game sprites.
